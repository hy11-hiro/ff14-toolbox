## スクリーンショット加工ツール

**ff14-screenshot-enhancer.html** は、FF14 のスクリーンショット向けに
簡易的な加工（まつ毛補正、コントラスト調整、軽微なレタッチ）を行うための静的 HTML ツールです。
ブラウザで開くだけで利用でき、追加のインストールは不要です。

### 公開ページ
https://hy11-hiro.github.io/ff14-toolbox/ff14-screenshot-enhancer.html

### 主な機能（予定含む）
- まつ毛の繊細な補正（強度調整スライダー付き）
- 目元のコントラスト強化
- スクリーンショットの軽微な色調補正
- Before / After の比較表示
- ローカルのみで動作する軽量処理（プライバシー配慮）

### ファイル構成
- `docs/ff14-screenshot-enhancer.html` — 加工ツール本体
- `assets/screenshot-enhancer/` — CSS / JS / アイコン等のリソース（必要に応じて）

# FF14 Mitigation Table

このファイルは Final Fantasy XIV のダメージ軽減（mitigation）参照表を単体で公開するための静的 HTML ページです。  
ブラウザで開くだけで利用でき、インストール不要です。

---

## 概要

**ff14-mitigation-table.html** はパーティ編成や軽減割り当ての確認を目的とした参照表です。パッチや運用ルールに合わせて値を更新し、打ち合わせや実戦準備で使えるよう設計しています。

---

## 主な内容

- **軽減カテゴリ別一覧**：スキルやバフごとの軽減率・対象・持続時間を表形式で表示。  
- **職業別メモ**：主要ジョブの注意点や割当例を短く記載。  
- **パッチ情報欄**：最終更新日と対応パッチを明記。  
- **印刷向けスタイル**：A4 印刷を想定した CSS を含む（印刷用レイアウトあり）。  
- **モバイル対応**：スマホでも見やすいレスポンシブ設計。

---

## 見方と利用上の注意

- **最終更新日と対応パッチを必ず確認**してください。ゲーム仕様の変更で数値が変わる可能性があります。  
- ページ内に出典や根拠を記載している場合は、参照元を尊重して利用してください。転載や再配布はライセンスに従ってください。  
- 実戦での割当はチームの運用方針に合わせて調整してください。本ページはあくまで参照用です。

## データ更新手順（簡易）

1. `ff14-mitigation-table.html` の `<tbody>` 内の行を編集してデータを更新。

3. GitHub Pages を利用している場合は公開ページを確認し、表示・印刷をチェック。
